# 选中文本后让 AI 修改

1. 在正文编辑器中选中需要修改的文字（也支持分栏和多个选区）。
2. 右侧输入框上方会显示“自动引用：文件名 · 行号”。点击“查看选中原文”可核对内容，点击叉号可取消引用。
3. 点击输入框，描述修改要求，例如“精简这两段，保持学术语气和引用不变”，然后发送。
4. 当前选择的模型会收到修改要求、准确的文件路径、行列范围和选中原文，并通过 OpenCode 的文件工具编辑。编辑后的内容会同步回编辑器。

选区在焦点移到聊天输入框后保留；在编辑器里重新选择会更新引用，取消选择、关闭对应编辑器或切换项目会清除引用。发送成功后本次引用清空，便于下一次操作。查看或选中文字本身不会发起模型请求。

发送前会先保存未保存的编辑，核对磁盘中的选区原文，并为目标文件创建本地历史备份。文件已发生变化、保存失败或备份失败时，会停止发送并保留输入要求。可通过“历史备份”恢复 AI 修改前的文件。

行列位置来自源文件，自动折行不会改变位置。引用只包含选中文字，不会自动附上整篇稿件；模型可能按要求读取该文件来核对上下文。选区范围是给代理的编辑指引，并非对 OpenCode 文件工具的硬性沙箱限制。发送涉及隐私的内容前，可在引用卡片中核对本次引用及当前模型。
