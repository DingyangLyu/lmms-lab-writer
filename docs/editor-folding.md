# LaTeX 编辑与折叠

LaTeX 文稿使用 CodeMirror 的原生正文输入，避免旧 Monaco textarea 覆盖层在 macOS 中文组词时造成长行重叠、变色或透明文字。其他代码文件和 Vim 模式仍使用 Monaco。

- 点击行号左边的小箭头，折叠或展开章节、子节，以及 `figure`、`table`、`tabular` 等成对环境。
- 连续的 `%` 注释可以折叠。单条很长的 `%` 注释也可收成一行摘要，即使它在文件里只有一个物理行。
- 顶部“注释”按钮收起当前文件的注释块；“当前块”收起光标所在的章节或环境；“全部展开”恢复全文。
- 点击绿色的“展开”占位标记也可恢复原文。macOS 可使用 `⌘⌥[` 和 `⌘⌥]`；其他平台使用 `Ctrl+Shift+[` 和 `Ctrl+Shift+]`。

折叠只改变编辑视图，不会删改源文件或加入换行。自动保存、历史备份和聊天选区引用使用完整文档。折叠状态目前保留在当前打开的编辑器中，重新打开文件时默认展开。

实现和测试包括章节层级、嵌套环境、注释中的伪命令、转义百分号、单行长注释，以及折叠/展开时源文完全一致。编辑器接收外部文件更新时只更新变化的文本区间；本地打字的状态回传不重建编辑器。
